Вопросы

Коротко о главном.

Нужен ли аккаунт, чтобы пользоваться браузером?

Нет. Аккаунт нужен только для Premium-подписки и синхронизации статуса доступа.

Как проверяется подписка?

Клиент спрашивает сервер при каждом запуске. Если сервер не подтвердил доступ — Premium считается неактивным. Данные, сохранённые локально, доказательством оплаты не являются.

Есть ли автопродление?

Нет. Подписка действует ровно оплаченный срок: 30 дней для месячного тарифа и 365 дней для годового.

Как удалить свои данные?

В панели управления или запросом DELETE /api/v1/me: аккаунт анонимизируется, все сессии отзываются, доступ закрывается.

Откуда браузер берёт обновления?

Из канала релизов на GitHub. Сервер отдаёт номер версии и ссылку на страницу релиза; решение об установке принимаете вы.
