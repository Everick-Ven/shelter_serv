# Проверка однофайловой демоверсии

Демо: `../shelter-demo.html`. Открывается двойным кликом, без Node.js и сервера.

Только для разработки: тест `standalone.cjs` использует `jsdom` (установить во
временный каталог, не добавлять node_modules в репозиторий):

```sh
npm install --prefix /tmp/shelter-demo-test jsdom
NODE_PATH=/tmp/shelter-demo-test/node_modules node demo-tests/standalone.cjs
```

Проверяет открытие HTML, обе роли, pending → paid, защиту от повторного webhook,
создание задачи, конверт доставки, fail-closed при ошибке проверки, autoInstall:false,
навигацию администратора, сохранение в localStorage, отсутствие внешних ресурсов
и ошибок JavaScript. Это DOM-тест, не проверка отрисовки реальным браузером.

Файл — изолированный симулятор, не настоящий backend. Разделение ролей организует
сценарии UI, не создаёт границу безопасности. localStorage не является доказательством
оплаты или подписки. Шифрование и Yjs не реализованы: симулятор доставки хранит только
метаданные, не выдает их за зашифрованные данные. Релизы вымышлены. Сброс восстанавливает
исходный набор данных. При запрете localStorage работа продолжается в памяти.
